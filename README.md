# Valen Info - High-Tech IT Solutions & Digital Agency

Welcome to **Valen Info**, a high-performance, modern web application for an innovative digital agency and enterprise IT solutions provider.

## Features & Branding
- **Brand Name**: Valen Info (`valen.info`)
- **Logo**: Custom geometric V+I monogram with emerald glowing accents and minimalist typography.
- **Tech Stack**: Next.js 16 (App Router), React 19, TailwindCSS, TypeScript.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:7878](http://localhost:7878) with your browser to see the website.

## Scripts
- `npm run dev`: Starts the Next.js development server.
- `npm run build`: Compiles the optimized production build.
- `npm run start`: Starts the production server.
- `npm run lint`: Runs ESLint for code formatting and quality checks.
